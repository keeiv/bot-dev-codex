# Visual assets

The BOT. mark and its original warm-to-cool gradients form the core of the identity. Square brackets distinguish the Codex package, while the stroke-drawn BOT.dev lettering and smaller CODEX label identify the plugin. All assets have transparent backgrounds.

- `icon.svg` / `icon.png`: square plugin icon.
- `wordmark.svg` / `wordmark.png`: dark lettering for light backgrounds.
- `wordmark-light.svg` / `wordmark-light.png`: light lettering for dark backgrounds.

This directory contains finished SVG and PNG assets. Artwork generation helpers are maintained locally and are not distributed with the plugin.
